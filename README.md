# 🎲 우리 반 모둠 나누기 (Class Group Maker)

수업 시간에 간편하고 공정하게 출석번호로 모둠을 나눌 수 있는 웹페이지입니다.  
별도의 프로그램 설치나 서버 구동 없이 **`index.html` 파일을 더블 클릭**하면 크롬이나 엣지 등 모든 브라우저에서 바로 실행됩니다. (오프라인 사용 가능)

---

## 🌟 주요 기능

1. **출석번호 기반 무작위 모둠 편성**
   - 총 학생 수(1~60번)와 모둠당 목표 인원수(예: 4명씩)만 지정하면 Fisher-Yates 알고리즘으로 공정하게 섞어줍니다.

2. **클릭 한 번으로 결석자 간편 제외**
   - 번호 칩을 클릭하여 결석한 학생을 즉시 제외하고 모둠을 편성할 수 있습니다.

3. **인원수 불일치(나머지 학생) 처리 옵션**
   - **골고루 분배하기**: 기존 모둠에 1명씩 나누어 넣어 비슷한 크기로 맞춤 (예: 25명 / 4명씩 → 5명 모둠 1개, 4명 모둠 5개)
   - **별도 모둠 생성하기**: 남는 인원만으로 마지막에 작은 모둠 생성 (예: 25명 / 4명씩 → 4명 모둠 6개, 1명 모둠 1개)

4. **모둠원 중 1명 모둠장(👑) 또는 역할 자동 선정**
   - 각 모둠에서 1명을 황금빛 모둠장(👑)으로 자동 지정합니다.
   - 모둠원은 그대로 유지한 채 **모둠장만 다시 뽑는 기능**도 지원합니다.
   - 필요 시 수업 역할(이끄미, 기록이, 지킴이, 발표이)도 자동으로 분담할 수 있습니다.

5. **수업 맞춤형 편의 기능**
   - **스마트보드/TV용 전체화면(⛶)** 지원
   - **드래그 앤 드롭 학생 이동**: 수업 중 선생님이 학생 번호를 끌어서 다른 모둠으로 즉시 조정 가능
   - **두구두구 추첨 애니메이션 & 내장 효과음 & 축하 폭죽 효과** (외부 인터넷 연결 불필요)
   - **원클릭 결과 복사 & 인쇄(PDF 저장)**: 학급 알림장이나 게시판에 바로 붙여넣기 가능
   - **설정 자동 저장**: 브라우저를 닫아도 학생 수와 설정이 그대로 기억됩니다.
